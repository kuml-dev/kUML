# Support-Ticket-Prozess der Muster-Firma GmbH (fiktives Beispiel)

> **Hinweis:** Dieser gesamte Workspace ist ein **frei erfundenes Beispiel**
> für das OKF (Open Knowledge Format). Die „Muster-Firma GmbH", ihre SLAs,
> Rollen und Prozesse existieren nicht — alle Angaben sind illustrativ.

Dieser Workspace ist ein zweites, thematisch bewusst anderes Beispiel für
einen **OKF-Wissens-Workspace** (`mode = knowledge`, siehe
[`.kuml-workspace.toml`](.kuml-workspace.toml)) neben
[`sample-association-charter`](../sample-association-charter/index.md) — hier
rund um den Support-Ticket-Prozess eines frei erfundenen Software-Anbieters,
inklusive eines Zustandsdiagramms, das sich eignet, um die
State-Machine-Simulation in kUML Desktop direkt an einem Wissens-Workspace
auszuprobieren.
