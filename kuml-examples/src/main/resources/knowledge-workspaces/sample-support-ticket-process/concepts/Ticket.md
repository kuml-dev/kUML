# Ticket (Muster-Firma, fiktives Beispiel)

Ein **Ticket** ist eine einzelne Support-Anfrage eines
[Kunden](Kunde.md), die von genau einem
[Supportmitarbeiter](Supportmitarbeiter.md) bearbeitet wird.

Geregelt in [§1 SLA-Definition](../articles/01-sla-definition.md). Der
vollständige Lebenszyklus eines Tickets — von der Eröffnung über die
Bearbeitung und eine mögliche Eskalation bis zum Abschluss — ist im
Diagramm [Ticket-Lebenszyklus](../models/ticket-lebenszyklus.md) modelliert.
Das zugehörige Datenmodell zeigt das
[Ticket-Datenmodell](../models/ticket-datenmodell.md).
