# Supportmitarbeiter (Muster-Firma, fiktives Beispiel)

Ein **Supportmitarbeiter** bearbeitet [Tickets](Ticket.md) von
[Kunden](Kunde.md). Es gibt zwei fiktive Rollen: reguläre
Supportmitarbeiter und Senior-Supportmitarbeiter, die eskalierte Tickets
gemäß [§2.2 Eskalationsprozess](../articles/02-eskalationsregeln.md)
übernehmen.
