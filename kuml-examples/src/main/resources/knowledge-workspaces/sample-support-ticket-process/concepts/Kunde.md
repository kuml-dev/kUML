# Kunde (Muster-Firma, fiktives Beispiel)

Ein **Kunde** ist eine natürliche oder juristische Person, die einen
Support-Vertrag mit der Muster-Firma GmbH hat und
[Tickets](Ticket.md) eröffnen kann.

Jeder Kunde hat genau einen zugeordneten Support-Level gemäß
[§1 SLA-Definition](../articles/01-sla-definition.md). Bei einer
Eskalation wird der Kunde gemäß
[§2.3 Kundenbenachrichtigung](../articles/02-eskalationsregeln.md)
automatisch informiert.
