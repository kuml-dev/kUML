= Service Blueprint notes
:description: Free-text notes in Service Blueprints and Journey Maps.

`note(text, vararg stepIds, id = null, kind = NoteKind.NOTE)` in a `blueprint(...)` block adds a note; a kind other than `NOTE` adds a symbol, an accent stripe and a tone (see xref:uml-dsl.adoc#note-kinds[Note kinds]). The ids are the values the step
functions (`customer(...)`, `frontstage(...)`, `backstage(...)`, `support(...)`) return.

Note text may use bold, italic, code, links and lists, see xref:uml-dsl.adoc#formatted-note-text[Formatted note text].

[source,kotlin]
----
blueprint(name = "Service") {
    lateinit var fill: String
    phase(name = "Request") {
        fill = customer(name = "Fills in the form", sentiment = Sentiment.NEUTRAL)
    }
    note("ASSUMPTION A1: the form is digital", fill)
    blueprintDiagram(name = "Blueprint", emotionCurve = false)
}
----

* Notes are drawn in a column right of the lanes, at the height of their first anchor; free-standing notes
  follow below. The canvas grows by one note column (276 px) only when the model has notes.
* Each anchor gets a dotted line with a dot at the card. The line runs through the free margin above the
  card, so it does not cross the cards of later phases in the same lane.
* An anchor that is no step is reported as `KUML-NOTE-W001`. A note that is not drawn is not reported as `KUML-NOTE-W002` for Service Blueprints yet.
* In a cell with several cards an anchor ends at its own card (see xref:blueprint.adoc[Service Blueprint]).
