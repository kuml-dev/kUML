= kUML Roadmap
:description: What kUML has delivered phase by phase, and where to find what is new.
:toc:

This page records the phases kUML has completed. It is a history, not a promise: for what changed
in each release, read link:CHANGELOG.md[CHANGELOG.md] or the
https://github.com/kuml-dev/kUML/releases[release notes]; https://kuml.dev/whats-new[kuml.dev/whats-new]
presents the same releases in a shorter form.

[NOTE]
====
The table below ends at v0.19.0 and has not been continued release by release since then.
Everything from v0.20.0 onwards (BPMN XML, ERM, SMIL animation, the web editor, Desktop workspaces,
the MCP server in Desktop, plugin signing, and more) is documented in the CHANGELOG.
====

== Known open items

* *GraalVM Native Image* is deferred (ADR-0009). Release binaries are JVM-based (jlink runtime
  bundles, no separate JDK needed).
* *SDKMAN!* distribution is built but not live: vendor onboarding is still pending. Use Homebrew,
  Chocolatey or the native installers meanwhile.
